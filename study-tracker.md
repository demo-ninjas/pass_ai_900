# AI-900 Study Tracker — 7-Day Cram Plan

> **Methodology**: READ → DRILL → RECALL
> - **READ**: Study the cheat sheets and MS Learn modules
> - **DRILL**: Work through flashcards and practice questions
> - **RECALL**: Close all materials and write down everything you remember, then check gaps
>
> Each day builds on the previous. Don't skip days.

## Exam Day Tips

| Tip | Details |
|-----|---------|
| **"Which service" questions** | The exam loves "which Azure service should you use?" — know the service names |
| **Responsible AI** | Memorize all 6 principles — at least 2–3 questions guaranteed |
| **Regression vs Classification vs Clustering** | Know examples cold — 2–3 questions guaranteed |
| **Don't confuse services** | Azure AI Vision ≠ Azure AI Face ≠ Azure AI Language ≠ Azure AI Speech |
| **Generative AI is 20–25%** | Heaviest domain — know Azure OpenAI, Foundry, and prompt engineering well |
| **Read carefully** | "Which service" vs "which workload type" are different questions |
